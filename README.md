Assignment 1 - Designing a Reactor

## Members of group 6:

## What the program does:
Using the "five factor formula" (k=nfpeP) the multiplication factor for a reactor (k) is calculated for both the beginning and the end of the reactor cycle. The reactor is assumed to be running at full power and at equilibrium.
