Assignment 1 - Designing a Reactor

## Members of group 6:
Linus Wesslén & Sigvard Hedström

## What the program does:
Using the "five factor formula" (k=nfpeP) the multiplication factor for a reactor (k) is calculated for both the beginning and the end of the reactor cycle. The reactor is assumed to be running at full power and at equilibrium. 

## How to run the programme:
The program is run in the main.py file. All assumptions and values are also listed in main.py, and it is in that file where changes to parameters can be made.

## What each file contains and how this GitHub is organized:
main.py contains all functions and parameters and is also where the code is run.

IMPROVMENT_LOG is a log concluding how the program has been developed, and it is based upon all previous commits made in all branches in the main.py file.

CODE_DOCUMENTATIONS.md states all assumptions made and largely matches the "Assumptions" section in the report.
